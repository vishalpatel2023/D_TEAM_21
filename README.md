# Computer Vision Based Road Safety Monitoring System

An Image Processing and Computer Vision project for detecting
road-safety violations and road hazards from images and videos.

## Modules

- Helmet Violation Detection
- Triple-Riding Detection
- Pothole Detection
- Automatic Number Plate Recognition (ANPR)

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express

### Computer Vision
- Python
- OpenCV
- YOLO
- NumPy
- PyTorch
- EasyOCR
